Adnan Menderes Üniversitesi Bilgisayar Programcılığı mezunuyum. Okul hayatımdan beri kendimi tutkuyla **C#** ve yazılım dünyasında geliştiriyorum. Oyun geliştirme ile başladığım serüvenime, şu an modern web teknolojileri ve yazılım mimarileriyle devam ediyorum.

### 🚀 Nelerle Uğraşıyorum?
- **Backend:** Yaklaşık 3 aydır **ASP.NET Core** ekosisteminde derinleşiyorum.
- **Frontend:** TypeScript tabanlı **Angular** ile projeler geliştiriyorum.
- **Oyun Geliştirme:** Unity ile geliştirdiğim 2 adet 2D oyun projem bulunuyor. Yakın gelecekte **Unreal Engine** dünyasına giriş yapmayı hedefliyorum.
- **Mimari:** Kod kalitesine önem veriyor; **Clean Architecture** ve **Domain-Driven Design (DDD)** prensiplerini projelerime entegre etmeye çalışıyorum.
